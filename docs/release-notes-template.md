## Download

| Your computer | Download | How to install |
|---|---|---|
| **Mac** (Apple Silicon or Intel, macOS 11+) | `Keelwire_…_universal.dmg` | Open it and drag Keelwire to Applications |
| **Windows 10 / 11** | `Keelwire_…_x64-setup.exe` | Run it. No administrator rights needed |
| **Linux** (most distributions) | `Keelwire_…_amd64.AppImage` | Make it executable, then double-click |
| Debian / Ubuntu, Fedora | `.deb` / `.rpm` | Install with your package manager |
| **Raspberry Pi** aboard (headless) | `keelwire-…-raspberry-pi-64bit.tar.gz` | See INSTALL.md; open it from any phone or laptop on the boat's Wi-Fi |
| No install at all | `keelwire-…-<platform>` archives | Run the program; it opens in your browser |

Nothing else needs to be installed. See [INSTALL.md](https://github.com/openseastack/keelwire/blob/main/docs/INSTALL.md) for first-launch notes.
